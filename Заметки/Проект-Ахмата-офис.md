# Пиксельный офис «Проект Ахмата» (ahmat-office.html)

## Что это
Интерактивный пиксельный офис в стиле ретро-игр, сделанный по фотографии заказчика. Отдельный HTML-файл, работает офлайн.

Файл: `~/Documents/MultiTool/HomeChats/Chat-31/ahmat-office.html`

## Структура (4 зоны, как на фото)

### Внешний вид
- Здание «Проект Ахмата» с вывеской-логотипом (квадрат с лицом), фасадом, окнами, дверью
- Дорожка из чёрно-белой плитки, газон, деревья, указатель
- Небо с облаками и солнцем

### Отдел 1 (Multitool) — рабочий
- **Начальник** (Ахмат, в тёмном) + **3 агента**:
  - Агент 1 — Диагност (🔍)
  - Агент 2 — Редактор (✏️)
  - Агент 3 — Технолог (🔧)
- Каждый за столом с компьютером, статусы «Ожидает → Работает → Готово»
- Кнопка «Запустить рабочий день» — анимирует работу

### Отдел 2 — Avito-бот (для продажи отдельно)
- Помещение с дверью, табличка «Avito-бот», пометка «можно продать отдельно»
- Идея: передача покупателю только этой зоны, без остального офиса

### Отделы 3 и 4 — свободные
- Пустые помещения с дверями, окнами, растением
- Готовы под будущих ботов

## Ключевая идея модульности
Офис разделён на НЕЗАВИСИМЫЕ зоны. Каждую зону (напр. Avito-бот) можно «отрезать» и передать отдельному покупателю, не отдавая весь проект и офис.

## Подключение к Cloudflare (реальные боты)
- Офис теперь связан с Cloudflare-воркером `blue-base-44d5`
- При нажатии «Запустить рабочий день» каждый агент отправляет POST-запрос в нейросеть Llama и выводит реальный ответ в лог
- URL воркера: `https://blue-base-44d5.halkeevahmat47.workers.dev`
- ⚠️ НО: workers.dev заблокирован из РФ без VPN → агенты вернут ошибку сети, если VPN выключен
- При включённом VPN агенты реально думают через нейросеть

### Версия: агенты-работники + чат (2026-10-13)
- **В каждом отделе (1–4) появился агент за столом** в верхнем правом углу (пиксельный персонаж с цветным экраном-жестом)
- Клик по агенту открывает **рабочую модель чата** — окошко, куда можно писать, агент отвечает по своей роли
- Роли: Отдел 1 — менеджер заказов, Отдел 2 — работа с клиентами, Отдел 3 — техподдержка, Отдел 4 — аналитика
- ⚠️ Сейчас чат работает в **локальном режиме** (агент отвечает заготовкой по роли). Подключение реальной нейросети (Cloudflare) добавит живые ответы — следующий шаг
- Проверено: status OK на 1440px и 390px

### Версия: профессиональные агенты + чёрный чат (2026-10-13)
- **Агенты стали профессиональными сотрудниками отделов** — каждая роль специализированная: Отдел 1 — заказы и отчёты, Отдел 2 — клиенты и продажи, Отдел 3 — техподдержка, Отдел 4 — аналитика
- Агент отвечает по своей роли, даёт **отчёт по отделу** («что сделал отдел»), умеет считать простые выражения (2+2=4)
- **Чат стал чёрным** — фон чёрный (не сливается с полом), текст контрастный, читаемый
- Локальный «мозг» агента — следующий шаг подключить реальную нейросеть

### Версия: узкая специализация агентов (2026-10-13)

- Агент отвечает только по своей теме; на чужой вопрос вежливо направляет к агенту нужного отдела
- «Что сделал отдел» → каждый даёт отчёт своего отдела
