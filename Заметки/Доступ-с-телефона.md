# 📱 Как открыть хранилище с телефона (GitHub)

Если вы потеряете связь с компьютером — вся библиотека работ доступна с любого устройства через GitHub. Этот файл — инструкция.

## Что уже сделано (на компьютере)
- `~/Documents/MultiTool/ObsidianVault/` превращена в **git-репозиторий**
- Сделан первый коммит (все 38 файлов / 35 заметок)
- История хранится локально в папке `.git/`

## Шаг 1. Создать аккаунт GitHub (один раз)
1. Зайдите на **github.com** → Sign up
2. Придумайте логин, почту, пароль
3. Подтвердите почту

## Шаг 2. Создать личный токен (один раз)
Токен — это «ключ» для git. Без него компьютер не сможет отправить файлы на GitHub.

1. На github.com → нажмите **аватар** (правый верхний угол) → **Settings**
2. Слева внизу → **Developer settings**
3. → **Personal access tokens** → **Tokens (classic)** → **Generate new token**
4. Название: `MultiTool Vault`. Срок: `No expiration`
5. В списке прав отметьте галочку **`repo`** (полный доступ к репозиториям)
6. Нажмите **Generate token** — появится длинный ключ вида `ghp_...`
7. **Скопируйте его сразу** (потом он больше не покажется) и пришлите мне

## Шаг 3. Я подключу и запушу
Когда пришлёте токен, я:
- создам репозиторий на GitHub под ваш аккаунт (`MultiTool-Vault`)
- подключу локальный репозиторий к нему
- отправлю (`push`) все изменения

## Шаг 4. Как читать с телефона
- Установите приложение **GitHub** (App Store / Google Play)
- Войдите под своим аккаунтом
- В профиле откроется репозиторий `MultiTool-Vault` — все заметки видны и редактируемы

Либо на телефоне в браузере: `github.com/<ваш-логин>/MultiTool-Vault`
